# Experiments reported in the paper

Scripts that produced the results of the paper that are not generated by the main pipeline of this repository (`main.py`). They are published as they were run, so they keep the absolute paths of the computing cluster (`/data/home/rtabares/Cervical/...`) and some comments in Spanish; to run them elsewhere, change the paths at the top of each script (or `BASE_PATH` in `config/settings.py` for the folders that contain a full project). All of them use the same curated data (`X_train.npy`, `y_train.npy`, `X_test.npy`, `y_test.npy`; see the main README).

| Folder | Result in the paper | Notes |
| --- | --- | --- |
| `table2_activation_filters/` | Table 2 (activation functions and preprocessing filters of the CoatCervix head) | `ActivationFilters.py` trains every combination of activation and filter and evaluates it on the test set. |
| `table3_efficientnet_filters/` | Table 3 (EfficientNet-B0 with each preprocessing filter) | One script per filter (`effUnsharp.py`, `effgamma.py`, `effclahe.py`, `effsharpen.py`); all use torchvision `efficientnet_b0` with ImageNet weights. |
| `table4_binary_single_runs/` | Table 4 and Figure 6 (single runs of the binary tasks on the test set) | The main pipeline with a label mapping (`data/label_mapper.py`). Each task is run by setting `LABEL_MODE` in `config/settings.py` to `"0vs1"` (Type 1 / Type 2), `"1vs2"` (Type 2 / Type 3), `"0vs2"` (Type 1 / Type 3), `"0vs12"` (Type 1 / Types 2 and 3), or `"01vs2"` (Types 1 and 2 / Type 3), with `num_classes = 2`, and running `main.py`. |
| `table5_table7_cross_validation/` | Table 5 (binary tasks, five fold cross validation on the training partition) and the CoatCervix folds used in Table 7 | Three copies of the same project that differ in `config/settings.py` (`LABEL_MODE` and `num_classes`): `multiclass_and_pairwise/` (`LABEL_MODE = "multiclass"`; the pairwise tasks were run by setting `LABEL_MODE` to `"0vs1"`, `"1vs2"`, or `"0vs2"`), `01vs2/`, and `0vs12/`. Run `main.py` in each folder. |
| `table6_baselines/` | Table 6 (single run of each baseline on the fixed split) | ResNet50, VGG16, VGG19, DenseNet201, Swin-Base, ConvNeXt-Large, and EfficientNet-B0 (`Efficient.py`, ImageNet normalization without filtering). |
| `table7_baselines_cross_validation/` | Table 7 (five fold cross validation of the baselines on the training partition) | One project per architecture (`convnext_large/`, `swin_base/`, `vgg16/`, `vgg19/`, `densenet201/`, `resnet50/`); the architecture is created in `training/train.py`. The evaluation of each fold on the test set is in `../revision/bloque_a_baselines.py`; EfficientNet-B0 and HMCFormer are in `../revision/`. |
| `table10_seeds/` | Table 10 (five random seeds) | Same pipeline as the main repository, with `run_pipeline(seed=...)`; `run_seed_experiment.py` runs seeds 42, 123, 2024, 7, and 99. |

The analyses added during the peer review (cross validation of the baselines with evaluation on the test set, statistical tests, latency, faithfulness of the explanations, and the figures) are in `../revision/`.
